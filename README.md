# Alagoas Tour 2021 — Excel Sales Dashboard

Interactive Excel dashboard developed to analyze sales performance, customer volume and tour revenue for Alagoas Tour in 2021.

## Dashboard

![Alagoas Tour Dashboard]()

## Project Overview

The dashboard provides an interactive view of key business metrics and allows performance analysis by sales representative.

### Key Metrics

* Total Revenue
* Number of Customers
* Average People per Booking
* Average Ticket

### Analysis

* Monthly revenue evolution
* Customer distribution by state
* Customer distribution by coastal region
* Top 3 tours by revenue
* Sales representative performance analysis
* Dynamic business insights

## Excel Skills

* PivotTables
* PivotCharts
* Interactive filters
* KPI development
* Lookup and aggregation formulas
* Data analysis
* Data visualization
* Dashboard design
